Privacy Policy — YouTube Post

Last updated: November 5, 2026

YouTube Post is a personal, locally-run tool used by its owner to upload videos to a single YouTube channel through the YouTube Data API v3. It is not offered as a public service and has no other users.

Data processed

  • Google account credentials: an OAuth 2.0 access token and refresh token, stored locally on the owner's computer. They are never transmitted to any third party.
  • Video files and metadata: the videos, titles, descriptions and tags supplied by the owner for upload.

Purpose

The data is used for one purpose only: publishing videos to the owner's own YouTube channel via the YouTube Data API.

Sharing

No data is sold, rented or shared with third parties. No analytics, advertising or tracking service is used. Nothing is stored on an external server.

Retention and deletion

Credentials and video files remain on the owner's computer until deleted. Access can be revoked at any time from myaccount.google.com/permissions, which immediately invalidates the stored token.

Google API Services User Data Policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Children

The tool is not directed to children and does not knowingly process data from children.
